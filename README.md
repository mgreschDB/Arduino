# Arduino Projekte - Elegoo Mega 2560 The Most Complete Starter Kit

Dieses Repository dokumentiert alle meine Arduino-Projekte mit dem **Elegoo Mega 2560 The Most Complete Starter Kit**.

## Ueber mich

Ich bin Anfaenger in der Programmierung und Elektronik. Dieses Repository dient als Lerntagebuch und Projektdokumentation.

## Projektstruktur

```
Arduino/
├── README.md                  # Diese Datei
├── DASHBOARD.md               # Projektuebersicht & Fortschritt
├── docs/
│   ├── kit-komponenten.md     # Alle Teile im Kit
│   ├── software-setup.md      # Installationsanleitung
│   └── projektideen.md        # Projektvorschlaege mit Schwierigkeitsgrad
├── projekte/
│   ├── 01-blink-led/          # Erstes Projekt: LED blinken lassen
│   ├── 02-ampel/              # Ampelschaltung
│   ├── 03-temperatur-sensor/  # Temperatur messen
│   ├── ...                    # Weitere Projekte
└── .kiro/
    └── steering/              # Kiro-Konfiguration fuer Unterstuetzung
```

## Wie ich arbeite

Ich nutze **Kiro** als AI-Entwicklungsumgebung, die mir bei folgenden Dingen hilft:
- Code schreiben und erklaeren
- Schaltplaene beschreiben
- Fehler finden und beheben
- Neue Projektideen entwickeln
- Dokumentation erstellen
